# StuHelp

StuHelp is an iOS application designed for university students to improve collaboration, discussion, and peer learning beyond Canvas.

## Features

- Discussion board for assignment help
- Study group creation and group chat
- Tips and resource sharing
- Canvas quick access integration
- Personal profile management
- Notifications and saved posts

## Technologies Used

- SwiftUI
- Xcode
- NavigationStack
- ObservableObject
- GitHub
